🔧 Limpar Cache do Navegador

Siga os passos abaixo para limpar o cache antigo e carregar a versão atualizada

⚠️ Importante: O Service Worker está cacheando a versão antiga. Você precisa limpar o cache para ver a nova versão.
1 Abrir DevTools
Pressione F12 ou Ctrl + Shift + I (Mac: Cmd + Option + I)
2 Ir para Application
Clique na aba "Application" no DevTools
3 Limpar Service Workers
No menu lateral esquerdo, clique em "Service Workers" → Clique em "Unregister" ao lado do worker ativo
4 Limpar Cache Storage
No menu lateral, clique em "Cache Storage" → Clique com botão direito em cada cache → "Delete"
5 Hard Reload
Pressione Ctrl + Shift + R (Mac: Cmd + Shift + R)
ou
Clique com botão direito no botão de atualizar → "Empty Cache and Hard Reload"
💡 Dica: Após limpar o cache, você pode fechar esta aba e abrir o app normalmente
